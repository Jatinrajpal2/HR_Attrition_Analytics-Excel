# 📊 HR Analytics Dashboard – Excel

An interactive HR Analytics Dashboard built using Microsoft Excel to analyze employee attrition and workforce trends.

## 📌 Project Overview

This project analyzes HR data to identify key employee attrition patterns and provide meaningful workforce insights through an interactive dashboard.

## 🔍 Key Insights

- 👥 Total Employees: **1,470**
- ✅ Active Employees: **1,233**
- 📉 Total Attrition: **237**
- 📊 Attrition Rate: **16.12%**
- 👤 Employees aged **26–35** recorded the highest attrition rate at **48.95%**
- 🏢 Research & Development recorded the highest attrition with **133 cases**
- ✈️ Employees who travel rarely recorded the highest attrition with **156 cases**
- ⚧️ Male employees accounted for **63%** of total attrition, compared with **37%** for female employees

## 🎯 Objective

The objective of this project is to transform raw HR data into an interactive dashboard that makes employee attrition patterns easier to understand and analyze.
